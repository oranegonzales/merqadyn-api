03 / Sync model

The server decides once.

  1. 01

    Accept a mutation ID

    A device-generated UUID makes every submitted change safe to retry.

  2. 02

    Resolve by mutation type

    Stock deltas commute. Stale product edits retain the current server version and create an audit record.

  3. 03

    Return ordered changes

    The response includes everything after the device cursor, ready for a local Room transaction.
